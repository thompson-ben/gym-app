# Gym App

A web app for planning workouts, logging training sessions, and tracking progress over time.

> **Status:** Early development. The project is being set up, so expect frequent changes.

## Planned features

- **Workout logging:** record exercises, sets, reps, weight, and rest times
- **Routines and programs:** build reusable workout templates and weekly plans
- **Exercise library:** browse exercises by muscle group and equipment
- **Progress tracking:** view history, personal records, and charts of volume and strength over time
- **Body metrics:** track bodyweight and measurements
- **Timers:** built-in rest and interval timers
